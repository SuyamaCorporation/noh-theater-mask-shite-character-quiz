# 能楽 能面・シテ方キャラクタークイズ

15種類の能面（翁・小面・般若・痩女・増女・若女・曲見・黒頭・大べし見・狐・中将・小尉・飛出・近江女・万媚）の説明文・特徴・演目から正しい面名を4択で答えるクイズアプリです。各問答後に面の特徴と使用演目の解説が表示され、カテゴリ別正答率で弱点を把握できます。

## 機能
- 3種のクイズモード（名前当て / 演目当て / 特徴当て）
- 15種類以上の能面データベース（説明・特徴・使用演目・カテゴリ）
- 4択形式の問題と解答後の詳細解説
- 連続正解ストリークカウンター
- カテゴリ別（翁系/若女系/鬼女系/鬼神系/老翁系等）正答率バー
- localStorageによる成績の永続保存
- 成績リセット機能
